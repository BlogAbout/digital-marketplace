## Регистрация

1. Перейдите на страницу регистрации
2. Заполните форму (имя, email, пароль)
3. Подтвердите email
4. Войдите в систему

## Покупка товара

1. Найдите товар через поиск или каталог
2. Откройте страницу товара
3. Нажмите "Купить"
4. Введите промокод (если есть)
5. Подтвердите покупку

## Продажа товара

1. Перейдите в Дашборд
2. Нажмите "Добавить товар"
3. Заполните информацию о товаре
4. Загрузите файл
5. Отправьте на модерацию

## Мессенджер

1. Перейдите в раздел "Мессенджер"
2. Выберите чат или создайте новый
3. Отправляйте сообщения

## Подписки

1. Перейдите на профиль продавца
2. Нажмите "Подписаться"
3. Получайте уведомления о новых товарах

## Поддержка

1. Перейдите в раздел "Поддержка"
2. Создайте тикет
3. Опишите проблему
4. Общайтесь с поддержкой
